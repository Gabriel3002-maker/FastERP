🧩 Studio-Flujo

Dibujá el flujo de tu proceso, agregá los campos que necesita, y generá un módulo instalable. Nada se escribe a disco hasta que apretás «Generar».

1. ¿Dónde va esto?

Minúsculas, sin espacios — se usa como identificador interno.

2. El flujo

«+ Estado» agrega una caja — arrastrala para acomodarla, tocá el texto para renombrarla. Arrastrá desde el punto de salida (derecha) de una caja hasta la entrada (izquierda) de otra para crear una transición; te va a pedir el nombre de la acción. La ⭐ marca cuál es el estado inicial.

Transiciones

Conectá dos estados para crear una.

Un diagrama de estados de Mermaid. La etiqueta de cada flecha es el nombre de la acción — [*] --> estado marca el estado inicial.

El dibujo del diagrama aparece acá.

3. Campos adicionales

El campo de estado se agrega solo, con las opciones que salen del diagrama. Estos son los demás datos que necesita el modelo.
